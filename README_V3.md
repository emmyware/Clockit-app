## ⭐ How to Use

**Upload Photos:**
1. Tap "Upload from Gallery"
2. Select up to 3 photos
3. They appear in gallery
4. Counter shows remaining

**Star Favorites:**
1. Open Gallery
2. Tap star icon on photo
3. Yellow = favorited
4. View in Favorites tab

**Check Stats:**
1. Tap hamburger menu
2. Select "My Profile"
3. See total, favorites, days active
